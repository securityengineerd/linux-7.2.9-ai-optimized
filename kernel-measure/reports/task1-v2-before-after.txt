What changed in v2 vs v1
  - llc_idle_enter() only writes the shared bit when it is clear (no write on bounce).
  - Bits are NOT cleared on leaving idle; a waker clears a stale bit after
    __select_idle_cpu() rejects the candidate.
  - select_idle_cpu_bitmap() ANDs LLC span & cpus_ptr & idle_cpus once, then
    walks with for_each_cpu_wrap starting at @target (cluster first when present).

v2 vs v1 (same workload, qualitative)
  Busy wake p50/p99 recovered a lot toward stock on V1 and V3 (14250/41500 and
  14500/43000 vs v1's 19500-28500 / 66250-92000). V2 is still a bad outlier
  (19750 / 78500). rq_latency is still bad on all three, though the mean is a bit
  lower than v1 (9.2 µs vs 11.3 µs). IPC no longer collapses the way v1's P1/P3 did.
  Migrations remain elevated vs stock on both patched kernels.
  Idle-target CPU changes stay high on v2 (135 / 233 / 127 permille), so wrap
  search still scatters wakees more than stock.

Verdict: STILL NOT A WIN vs stock. Task 1 v2 FAILS this measurement.
  - The busy-wake regression that killed v1 is mostly gone on 2 of 3 runs, but
    pair signs are mixed, so it is not a claimed win either.
  - rq_latency_ns is still a clear regression on all 3 pairs (+48..+138% against
    ~6% stock noise). That alone is enough to fail the task.
  - Idle p50 looks better on all 3 pairs, but idle p99 is worse on all 3 and the
    idle numbers swing hard run to run. Not a clean result.
  - Migrations and idle CPU-target changes stay much higher than stock.
  - general is flat (no harm, no help).

Recommendation
  Do not ship Task 1 in this form. Options:
  1. Drop Task 1 and move on to Task 2 (migration policy), keeping stock idle search.
  2. One more redesign: keep the bitmap as a hint only for the first candidate
     (or a short fixed-size peek) and never replace the capped linear walk; or
     make the bitmap per-CPU / local so the waker does not bounce a shared line.
  3. Accept Task 1 as failed on this box (single LLC, 12 CPUs) and defer until a
     multi-LLC machine can show a real SIS win.

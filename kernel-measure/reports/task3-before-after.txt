What the patch actually changes
  Survey option (B), narrowed prototype:
  - Gate: sysctl kernel.sched_cgroup_dl_servers (default 0) + static key.
    Feature off => no servers allocated; stock path unchanged.
  - When on: on cpu.max write, admit a per-CPU dl_server for bandwidth-root
    groups (own cpu.max set; no ancestor below root also has quota). Covers
    depth-1-under-root with cpu.max and deeper first-capped leaves (harness
    throttle groups under kmeas.slice).
  - Server pick uses pick_task_fair_from() starting at that group's cfs_rq,
    not always root.
  - CFS period refill / throttling remain authoritative (no silent bypass of
    distribute_cfs_runtime). DL server is an additional fair_server-style pick
    path (50ms/1000ms params).
  - Hierarchical cpu.weight among opted-in siblings is NOT rebuilt — weight
    sharing may be wrong/ignored on the DL pick path. Prototype for
    enqueue/bandwidth-timer cost, not a shipping cgroup redesign.

How to enable
  sudo sysctl -w kernel.sched_cgroup_dl_servers=1
  Enable BEFORE creating capped cgroups (or rewrite cpu.max after enabling);
  admit/detach is hooked from tg_set_cfs_bandwidth.

Verdict: INCONCLUSIVE — not a claimed win, not a clear fail.
  - No primary metric clears stock run-to-run noise with the same sign on all
    three pairs.
  - cycles tick down a hair on every pair but sit at the stock noise floor
    (~0.03%); do not treat as a Task 3 win.
  - rq_latency and weight_err swing both ways; weight_err noise alone is huge
    (~50%), consistent with "hierarchical cpu.weight NOT rebuilt".
  - Throttling semantics look intact: wl_nr_throttled stays ~240 and
    wl_throttled_usec stays in the same band as stock (no silent throttle
    bypass).
  - Feature was ON for all patched runs (sysctl=1). Smoke create of a
    cpu.max leaf under a slice did not oops.

Recommendation
  1. Keep 0003 as the Task 3 prototype candidate; full hierarchical weight
     rebuild and true "DL server replaces period refill" remain future work.
  2. On this box, park Task 3 as "no decision" for cycles/rq_latency; the
     prototype is compile-safe, gated off-by-default, and measured.
  3. GRUB currently boots 7.2.9-t3; 7.2.9-baseline and 7.2.9-ai-opt remain
     installed for re-entry.

Caveats
  - Patched and stock were collected ~30 minutes apart on different boots.
  - 3 runs per side. Feature admits bandwidth-root groups; DL params match
    fair_server (not the group's cpu.max ratio), so this measures an extra
    pick path more than a bandwidth replacement.
  - Patch path: patches/0003-cgroup-deadline-servers-prototype.patch
